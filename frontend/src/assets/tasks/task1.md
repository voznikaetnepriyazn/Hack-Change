# Задача: Настроить локальное окружение

**ID:** `ALPHA-101`
**Статус:** В процессе
**Дедлайн:** Сегодня, 15.11.2026

## Описание
Для того чтобы начать писать код, тебе нужно развернуть сервис на своём ноутбуке. Выполни следующие шаги:

1. Установи внутренний инструмент `avito-cli`. Инструкция по установке находится в Confluence (пространство команды Alpha).
2. Склонируй репозиторий `alpha-backend-api` из Bitbucket.
3. Запусти локальные Docker-контейнеры с PostgreSQL и Redis.
4. Проверь, что сервис собирается и отвечает на `localhost:8080`.

## Критерии готовности (Acceptance Criteria)
- Локальный сервис успешно запускается.
- При переходе на `localhost:8080/health` возвращается статус `200 OK`.
- Ты можешь сделать коммит и запушить его в свою ветку.
