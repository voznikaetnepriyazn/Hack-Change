# Задача: Написать API-эндпоинт для получения статуса заявки

**ID:** `ALPHA-142`
**Статус:** Завершено
**Дедлайн:** 07.11.2026

## Описание
В рамках интеграции с AI-buddy нужно реализовать эндпоинт, по которому бот сможет узнавать статус заявки (например, отгула), созданной стажёром.

1. Создай обработчик (handler) для GET-запроса по пути `/api/v1/requests/{id}`.
2. Напиши логику получения статуса заявки из базы данных PostgreSQL по её ID.
3. Настрой возврат JSON-ответа с полями `status`, `created_at`, `updated_at`.
4. Добавь обработку ошибок (возврат 404, если заявка не найдена).

## Критерии готовности (Acceptance Criteria)
- Эндпоинт возвращает корректный JSON для существующей заявки.
- При несуществующем ID возвращается код 404.
- Код успешно прошел ревью у Дмитрия Волкова и смержен в ветку `develop`.
