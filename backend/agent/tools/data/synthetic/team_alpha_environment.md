# Техническая среда и доступы команды Alpha

Чтобы начать писать код и приносить пользу, тебе нужно настроить локальное окружение и получить необходимые доступы.

## Настройка локального окружения
1. Установи **avito-cli** (внутренний инструмент для работы с сервисами Авито). Инструкция по установке находится в Confluence (пространство команды Alpha).
2. Склонируй репозиторий нашего сервиса из Bitbucket.
3. Для управления локальными микросервисами мы используем Kubernetes. Тебе понадобится инструмент **LENS** — запроси доступ у Игоря Петрова.
4. Для перехвата запросов используем сниффер **bruno** или **charles**.

## Где что искать
- **Логи нашего сервиса:** Хранятся в **Grafana**. Доступ к дашбордам Grafana запрашивается через Jira (проект IT-Support).
- **Архитектурные схемы:** Все актуальные диаграммы (C4) лежат в **Confluence** в разделе «Архитектура команды Alpha».
- **База данных:** Мы используем PostgreSQL. Для получения доступа к тестовой базе данных напиши Игорю Петрову (Middle Backend Developer).
- **Продуктовые метрики:** Строим дашборды в **Redash** и **Tableau**. Доступ к Redash запрашивается через твоего наставника (Дмитрия).

## Код-ревью
- Каждый Pull Request (PR) должен пройти ревью.
- Основной ревьюер — **Дмитрий Волков**. Если он занят или в отпуске, ревью может провести **Артём Соколов**.
- Перед отправкой кода на ревью убедись, что все автотесты (CI в TeamCity) проходят успешно.
