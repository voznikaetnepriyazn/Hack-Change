# Рабочие процессы команды Alpha

Наша команда работает по методологии Scrum. Мы верим, что небольшие и частые релизы приносят больше пользы, чем редкие и крупные.

## Ритуалы и встречи
- **Daily (Дейли):** Каждый день в 11:00 МСК в канале `#team-alpha-daily`. Обсуждаем, что сделали вчера, что делаем сегодня и есть ли блокеры.
- **Sprint Planning (Планирование спринта):** Проходит раз в две недели (по понедельникам). Длительность спринта — 2 недели.
- **Ретроспектива:** В конце каждого спринта (по пятницам) обсуждаем, что было хорошо, а что можно улучшить.

## Процесс разработки
1. Задачи берутся из **Jira** (проект Alpha-Backend).
2. Для каждой задачи создается отдельная ветка в Git (Bitbucket).
3. После написания кода создается Pull Request (PR).
4. PR проходит код-ревью (основной ревьюер — Дмитрий Волков).
5. После успешного ревью и прохождения тестов в TeamCity (CI) код мержится в основную ветку.

## Релизы
Мы работаем по модели Continuous Delivery. Релиз нашего сервиса происходит каждый четверг.
Если ты хочешь увидеть результат своей работы, после релиза зайди в наш прод (production) и проверь фичу.

## Документация
Все технические спецификации, гайды и архитектурные решения мы храним в **Confluence** в пространстве команды Alpha. Если ты написал новую фичу — не забудь обновить документацию.
